The agent can only do what its user could do, and nothing the user didn't ask for.

__BRAND__ is a deterministic security layer between the application and the LLM. On every message it builds the tools this particular user may use, fills identity arguments from code, asks for approval before any action with side effects, and records everything in a hash-chained log. Rules decide; the classifier can only make them stricter.

Five layers

Each layer stops a different failure; none of them trusts the LLM.

①

Deputy Firewall

The role policy decides which tools exist in each run. Identity arguments are filled by code, not by the model.

policy.py · firewall.py
②

Siren Guard

A classifier at checkpoints G1, G2, G2b and G3: input, tool results, before a sensitive action, the answer.

classifier.py
③

Canary

A per-conversation canary in the system prompt and decoy honey records: a leak shows up and is cut off.

canary.py
④

Bound approvals

Human approval bound (HMAC) to the exact arguments, single use, expiring after 5 minutes.

approvals.py
⑤

Audit & control

A hash-chained audit log, a kill switch and a live console for the administrator.

audit.py · killswitch.py

Private data never reaches the model

Declared personal data (AMKA, IBAN, ΑΦΜ, phone, e-mail, ID card, address, date of birth) becomes a typed placeholder before the model or the classifier sees it. Only __BRAND__ maps it back, and only where the role's filters already show the value.
